# Crib Market

Marketing site for Crib Market, a multi-asset CFD broker. Built from the Roventar codebase with a Crib Market logo, Hantec-inspired header, and rewritten copy.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3030](http://localhost:3030) if that port is in use, or the port printed by `next dev`.

Auth CTAs point at `https://client.cribmarket.com/`.
